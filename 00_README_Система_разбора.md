# Система разбора карты Джйотиш — v2.0

Комплект из 10 промптов + шаблон вёрстки. Результат — клиентский PDF уровня «Книги судьбы».

## Что изменилось по сравнению с v1.0 (7 промптов)

| Было | Стало | Почему |
|---|---|---|
| Сбор данных не был отдельным этапом | **Промпт 01** — полный технический экспорт | Разбор регулярно упирался в отсутствие варг; без D2/D4/D6/D7 половина сфер оставалась общими словами |
| Биография запрашивалась «по ходу» | **Промпт 03** с жёстким гейтом | Этап пропускался, и весь разбор шёл без проверки реальностью |
| Оценок /100 было два вида вперемешку | Введено **три раздельных шкалы** с разными названиями | «85/100» за паттерн и «68/100» за путь души — разные вещи, их путали |
| Путь души не считался | **Промпт 07** — послойный расчёт с весами | Иначе это «на глаз», что противоречит всей методике |
| Упаи писались в конце «как получится» | **Промпт 08** — отдельный этап со спецификацией | Раздел систематически не дописывался или выходил шаблонным |
| Вёрстка описывалась словами | **Файл 11** — готовый HTML/CSS-шаблон | Дизайн каждый раз собирался заново |

## Порядок работы

Промпты отправляются строго по порядку: 01 → 10.
Не переходить к следующему, пока предыдущий не завершён.
В начало каждого промпта (кроме 01) вставляется **сводка предыдущего этапа**, которую ИИ формирует в конце каждого файла.

Если промпты идут в разных чатах — в начало каждого нового чата вставлять:
1. Технический экспорт из Промпта 01 (целиком).
2. Все накопленные сводки предыдущих этапов. Не сокращать их самостоятельно.

## Источник данных — абсолютное правило

Все астрологические данные берутся из расчёта **vedic-horo.ru** (личный кабинет пользователя).

> ИИ не выполняет астрономических вычислений. Не пересчитывать положения планет, градусы, куспиды домов, даты даш. Если данных не хватает — писать «НЕДОСТАТОЧНО ДАННЫХ» и запрашивать, но никогда не додумывать числовые значения.

**ИИ не может зайти на сайт сам** (нужна интерактивная форма расчёта). Данные передаёт пользователь — скриншотами или текстом. Это не ограничение конкретной модели, а свойство задачи: планируйте этап 01 как ручной.

## Три шкалы — не смешивать

Это главный источник путаницы в v1.0. Каждая шкала имеет своё имя и свою методику:

**1. «Опора N» (0–100)** — насколько прочно вывод держится на карте: число независимых подтверждений минус сила противоречащих. Применяется к паттернам и выводам. Не вероятность, не процент.

**2. «Уверенность»** — словесная, три градации: высокая / средняя / гипотеза. Применяется к каждому отдельному утверждению.

**3. «Пройденность пути души» (0–100%)** — единственная шкала, выражаемая в процентах. Считается только в Промпте 07, только послойно, только при подтверждённом времени рождения. Авторская, не классический Джйотиш.

Запрещено: складывать шкалы между собой, выражать «опору» в процентах, использовать шкалу пути души где-либо кроме своей главы.

## Последовательность мышления на каждом шаге

**найти паттерн → минимум 3 независимых подтверждения → активно искать противоречия → оценить опору → сверить с жизнью → пример → зрелое/незрелое проявление → конкретное действие**

## Что считается независимым подтверждением

Не всякие три факта независимы. Независимыми считаются показатели из **разных слоёв**:
- положение/достоинство планеты в D1
- управление домами (функциональный статус для данной лагны)
- подтверждение в варге (D9, D10, D60 и др.)
- сила (Шадбала, Аштакаварга-бинду)
- караки (Атмакарака и др.)
- йога, условие которой выполнено полностью

Три следствия одного и того же факта — это одно подтверждение, а не три. Так, «Сатурн экзальтирован», «Сатурн в лагне» и «Сатурн сильный» — это один слой, если все три читаются с одной строки таблицы.

## Обязательное раскрытие ошибок

ИИ обязан ловить, исправлять и **явно документировать собственные ошибки** — прямо в тексте этапа, а не молча. Типичные: транспозиция строк Раху/Кету, путаница «дом размещения» vs «управляемый дом», неверное определение Атмакараки (берётся планета с наибольшим градусом, узлы в 7-караковой системе не участвуют), конфликт достоинства между варгами.

Прозрачное раскрытие ошибки — признак качества, а не провала.

## Честность важнее красоты

- Если данных нет — «НЕДОСТАТОЧНО ДАННЫХ» лучше красивой неподтверждённой интерпретации.
- Если биография противоречит карте — пересматривается интерпретация, а не биография.
- Если человек богат, а показатель выглядел неблагоприятно — искать, что реально объясняет результат, а не оставлять вывод «слабый финансовый потенциал».
- Нельзя выдавать гипотетический пример за произошедшее событие. Формулировка для непроверенных примеров: «Например, это может проявляться так…».

## Правило непотери содержания

«Усиль X» не означает «убери всё остальное». Ранее включённый материал не исчезает без явного указания его вырезать.

## Разделение слоёв

Технический анализ (полная терминология) и клиентский текст (без жаргона) — разные документы. Тест на ценность: если убрать из абзаца астрологические термины и ничего существенного не осталось — абзац демонстрировал расчёт, а не приносил пользу. Такой абзац вырезается.

## Границы

Карта не позволяет определить: дату смерти, гарантированное событие, медицинский диагноз, количество детей, подробности прошлых воплощений, число воплощений. Медицина, юриспруденция и финансы — приоритет у профильных специалистов.

Запрещено: запугивающие предсказания; формирование зависимости от астролога, ИИ, камней или ритуалов; безальтернативные утверждения о будущем.
